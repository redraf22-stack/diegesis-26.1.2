# Diegesis — порт на Minecraft 26.1.2 (Fabric)

**Неофициальная сборка.** Порт библиотеки [Diegesis](https://github.com/Pocky-l/diegesis) автора **Pocky**
с 1.21.1 на **Minecraft 26.1.2** (Fabric, Loom 1.17, Java 25, mojmap).

## Что это

Библиотека интерфейсов прямо в мире: камера подъезжает к блоку, и игрок работает с его объёмными частями —
без отдельного экрана. Сцены описываются JSON-файлами (`assets/<namespace>/diegesis/scenes/<id>.json`),
поведение станций — кодом на стороне мода, который её использует.

Содержит: рендер сцен (модели, предметы, жидкости, тени, световые пятна, частицы), камеру и FOV сцены,
книги рецептов, слоты и перетаскивание, обводку под курсором, синхронизацию состояния станций.

## Установка

Библиотека нужна только тем модам, которые её используют (например **Hands-On Delight** для 26.1.2 — см. его релизы).
Сама по себе ничего в игре не добавляет.

1. **Minecraft 26.1.2**, **Fabric Loader 0.19.5+**, **Java 25**, **Fabric API 0.155.2+26.1.2**.
2. В `mods` положить `diegesis-1.0.0-beta.9+26.1.2.jar`.

## Сборка

```bash
gradle build --offline      # нужен JDK 25
```

Журнал порта (рендер сцен, камера, миксины, грабли 26.1) — в `PORT_NOTES.md`.
